WikiMove – Proposed System UI Prototype Portal

🎓 Academic Prototype (6 Screens)

WikiMove: UI Prototype Suite

A complete visual representation of the proposed knowledge base migration and governance system, built with clean HTML, CSS, and minimal JavaScript in compliance with academic requirements.

📁 14,000 Total Pages • ⚡ 7,000 Kept Pages (50%) • ⏱️ 42-Wk Estimate vs 39-Wk Licence
Screen 1

Executive Dashboard

High-level KPI cards for total pages (14,000), reviewed pages, kept vs deleted, overall migration progress, and licence expiry status.

 Screen 2

Page Triage Queue

Interactive triage queue for engineering teams to evaluate pages at 40 pages/day and select Keep, Archive, or Delete.

 Screen 3

Detailed Page Review

In-depth inspection interface displaying legacy page content, metadata, review notes, and mandatory named owner assignment.

 Screen 4

Migration Dashboard

Batch execution tracking for the 7,000 kept pages at 25 pages/day with progress bars, validation states, and error handling.

 Screen 5

Ownership Management

Post-migration governance registry binding each active page to a named custodian to enforce 90-day review cycles and eliminate orphan decay.

 Screen 6

Risk & Schedule Status

Evaluates all four project risks (R1-R4) by exposure $E = P \times I$ and presents the mathematical schedule gap analysis (+3.0 weeks overrun).
